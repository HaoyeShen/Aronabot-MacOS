# 500 MB 以内的安装包

提供两种独立安装包，均适用于 Apple Silicon、macOS 13+。微信内部接口固定支持原版微信 4.2.0（270348）及已验证的核心指纹。

## Aronabot-MacOS 机器人在线安装版

打开 pkg，系统安装向导完成后会自动打开「Aronabot-MacOS 安装助手」。选择原版微信和目标目录，点击「开始安装」；程序自动安装机器人、SDK、原生组件、Python/Tk、可移植角色语音推理环境，并自动下载约 1.17 GB 的公开语音模型。下载显示 MB 进度，支持中断缓存和 SHA-256 校验，无需手动 pip 或安装 Python。

需要可访问 Hugging Face 的网络。500 MB 限制针对分享的 pkg 文件，安装后的运行环境、模型、缓存和微信副本会占用更多磁盘空间，建议预留至少 10 GB。个人参考录音、模型 API Key 和监听目标需要由使用者自行配置。

## Wemac-auto SDK 安装包

打开 pkg 后，使用「Wemac-auto SDK 安装助手」选择目标目录；安装原生 SDK、命令行运行环境、编码器和独立微信副本，不下载机器人语音模型。

安装目录中的 `bin/wechat-aumac --help` 可查看命令；原生 profile 位于 `~/Library/Application Support/WemacAuto/Arona/native-profile-isolated.json`。调用时用各子命令的 `--profile` 指定该文件。SDK 源码和示例位于安装目录的 `sdk`。

## 共同规则

- 可编辑完整安装路径，或用「选择」按钮选择上级目录。
- 系统安装向导与配置助手均显示进度；复制和重签名按阶段显示，在线模型按下载字节显示。
- 不提供或分发微信本体，使用收件人自己安装的受支持版本创建副本。
- 不包含开发者的聊天记录、账号、Keychain、API Key、私人录音和本地训练资料。
- 不停止或重启正在运行的微信；发现已有目标、独立账号容器或配置时不覆盖。
- 两个安装包提供不同用途的安装入口，共用同一独立微信身份；不用于同一台电脑创建多个同身份客户端。
- 程序使用本地 ad-hoc 签名；pkg 没有 Developer ID 签名与 Apple 公证，macOS 可能要求使用者按系统提示允许打开。安装器不关闭 Gatekeeper 或 SIP。

构建命令：`.venv-bot/bin/python packaging/build_pkg.py --online` 或 `--sdk-only`。在线版先准备 `packaging/.build/voice-runtime.tar.gz` 与带固定版本、文件大小、SHA-256 的 `packaging/payload/online-models.json`。
