# 日记与朋友圈评论调度

日记发布需要开启 diary_enabled，时间使用北京时间；自动评论需要开启 moments_comment_enabled。单独填写时间不会启用任务。设置页提供“应用日记与评论设置”，独立校验并保存开关、时间和间隔，不受其他设置项校验影响。

朋友圈调度使用独立于新闻抓取的线程，连接后立即检查过期任务，每25秒检查一次；新闻抓取不会阻塞日记，日记异常不会阻止评论检查。消息正在处理时暂缓任务。日记按本地日期保留发布记录，已发布或结果不确定时不重新提交；恢复连接后补执行当天已经到时但尚未提交的日记，不补发过去日期。

自动评论读取近24小时其他人的文字动态，由模型决定是否评论；一到三字短文案同样进入判断。跳过后五分钟检查下一个候选，实际评论仍遵守配置间隔。每条动态有持久记录，pending/uncertain 不自动重发，已确认、已处理的目标不重复评论。模型跳过不代表发送失败；功能不保证每天一定发表评论。尚未提供的图片和视频不冒充已经看过。

2026-11-17 本机修复时确认两个持久开关原为关闭；启用后当天配图日记通过原生接口获得服务器确认。评论实际读到一条近24小时的三字动态，修复筛选后模型选择跳过，未强制留言。微信进程没有重启，私有朋友圈内容与状态文件不分发。
