# 节省模式

默认关闭。在设置的“推理强度”区域打开“节省模式”，填写已安装的本地 Ollama 模型，点击“保存设置”。“检查本地模型”可验证服务和模型清单。关闭后恢复原有模型路由。

当前本地任务白名单：短上下文摘要、关键词是否对机器人说话、群聊回复对象分类、概率命中后的简单回复判断。它们只生成文字，不获得微信发送或工具执行权限。现有概率回复、@和关键词必回规则不因模式改变。正式回复、Agent 工具决策、图像/文档理解和朋友圈发布/评论决策继续使用原模型。

本地服务固定为 127.0.0.1:11434，不向它发送云端 API Key。初始模型为 qwen3.5:9b；可填写本机其他已安装模型。不会自动下载权重；模型缺失或服务异常时使用原模型。安装了 Ollama 但服务未启动时，会尝试启动本机 Ollama serve。模型运行会占用内存和算力，开启节省模式不代表完全离线。

本地请求关闭思考，单轮超时10秒，摘要最多700输出 tokens，分类最多32。多媒体输入、超长输入和非白名单任务不分流。分类必须符合固定枚举，摘要需通过基本格式校验；失败回退原模型，并暂停尝试本地60秒。摘要仍有模型误差，不应将其作为原始聊天记录。日志记录本地完成与回退次数；本地 tokens 与云端模型调用按实际提供方记录，不伪造固定节省百分比。

本机验收复用了已有 qwen3.5:9b：正反分类及多人约定摘要通过真实本地推理，无云端模型请求。离线测试覆盖默认关闭、设置持久化、白名单、多媒体/长文绕过、输出无效回退与冷却；原有后台、概率及缓存回归检查通过。

接口参数依据 [Ollama 官方 API](https://github.com/ollama/ollama/blob/main/docs/api.md)。
