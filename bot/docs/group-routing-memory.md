# 群内单人必回复与跨聊天记忆

管理员名单中的成员可以在已监听群发送 `/singlechat @无歧义昵称` 或 `/singlechat wxid_xxx`。名字通过当前账号的联系人内部接口解析为稳定 ID；不能唯一解析时不会启用。只选择一个人，重复指令替换当前选择。该群中被选择者绕过概率抽签；其他人即使 @机器人或命中关键词也不会触发回复。

退出指令为 `/singlechat off`、`/singlechat exit`、`/singlechat 退出`、`/singlechat 结束` 或 `/endsinglechat`。非管理员的进入和退出指令均被忽略。原生群消息同时验证稳定发送者 ID，不能仅靠改昵称冒充管理员。模式按群保存，重开机器人仍保留；私聊不受影响。停机、消息去重、过期防护和主动关闭自动回复仍生效。

`bot.shared_memory_enabled=true` 启用全局背景记忆；各聊天的原始上下文、摘要水位、任务续接和消息发送目标继续独立。共享内容标明来源，只作参考，不能被当成本轮用户或管理员授权；同名不同账号不自动合并身份。管理员密码、指令、私聊管理操作与凭据会被排除。可在每个目标的 `shared_memory_enabled` 单独选择共享范围，或关闭全局开关。

资料导入是本地检索增强（RAG），不是更新 DeepSeek 模型权重。原账号历史仅允许经可访问的已登录客户端读取或由用户导出的文件导入；不会为导出而修改原版签名、关闭 SIP 或重启正在运行的 WeChat-Wemac。私人语料和游戏资料下载不进入公开仓库或分享安装包。
